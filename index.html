03 — Advanced

Advanced options

Excludes look-alike characters (0/O, 1/l/I, 2/Z …) and keeps only clearly visible symbols.

Excludes characters that sound alike when spoken (B/C/D/E/G/P/T/V/Z, M/N, 1/7), so every character is heard unambiguously.

Splits the password into blocks of four with a separator (e.g. k3WF-pmQx) so it can be read out chunk by chunk. The separator never appears inside the password itself.

All generation happens locally in your browser — no network requests, no storage, no tracking.
