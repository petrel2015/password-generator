# 故障排查

English version: [Troubleshooting](../en/troubleshooting.md).

下表每一行都对应真实代码路径——`js/app.js` 的警告态、`js/generator.js` 的错误分支、`js/donation.js` 的回退逻辑。

## 生成

| 症状 | 可能原因 | 修复 |
| --- | --- | --- |
| 密码区显示 `——————` 并提示「请至少选择一种字符类型。」 | 四个字符类型全部取消勾选 | 至少勾选一类 |
| 密码区显示 `——————` 并提示「没有可用字符了——请调整黑名单。」 | 黑名单（可能与高级选项叠加）把候选字符全部排除 | 删减黑名单字符或增选字符类型 |
| 熵值比预期低 | 高级选项（易输入 94 → 55、易朗读 94 → 49、叠加 → 35）或黑名单缩小了候选池——数字对当前设置而言是对的 | 属预期行为；见[使用 — 读取熵值与强度](./usage.md#读取熵值与强度) |
| 键入的长度不生效（如 `99`） | UI 在变更时把长度收敛到 4–64 | 使用 4–64 之间的值 |
| 报错「Web Crypto API unavailable」（极旧浏览器） | 浏览器早于 `crypto.getRandomValues`（如 IE 11 或极旧的内嵌 webview） | 换用当前的 Chrome、Edge、Firefox 或 Safari |

## 复制

| 症状 | 可能原因 | 修复 |
| --- | --- | --- |
| 「复制」没有闪「已复制」 | 剪贴板写入失败：剪贴板 API 不可用（非安全上下文）**且**旧式 `execCommand` 兜底也被拒绝 | 手动选中密码文本 Ctrl/Cmd+C；以 HTTPS、localhost 或 file:// 打开即可恢复 API |
| 剪贴板里是旧密码 | 点复制发生在最新一次重新生成之前 | 密码更新后再点一次复制 |

## 语言

| 症状 | 可能原因 | 修复 |
| --- | --- | --- |
| 语言在两次访问间被重置 | localStorage 不可用（隐私模式）或被清空；检测回退到浏览器语言 | 无法修复——没有存储就无法持久化，每次访问手动切换 |
| 页面出现混合语言 | 某个键在 `js/i18n.js` 的某一份词典里缺失——`t()` 先回退英文、再回退键名本身 | 把键补进两份词典；见[开发 — 约定](./development.md#约定) |

## 赞赏弹窗

| 症状 | 可能原因 | 修复 |
| --- | --- | --- |
| 「二维码生成失败，请重试。」 | 内联的 `js/vendor/qrcode-generator.js` 加载失败（文件缺失，或离线打开了不完整的副本） | 确认 `js/vendor/qrcode-generator.js` 与页面同在；关闭再打开弹窗会重试加载 |
| 手机上点支付宝标签页看似无反应 | 已发生向支付宝 App 的跳转，或被系统拦截；弹窗正在等可见性计时器 | 约 1.3 秒后自动回退二维码，或直接点「显示二维码」 |
| 微信标签页从不拉起 App | 设计如此——微信深度链接是支付载荷，浏览器无法可靠拉起 | 用微信 App 扫码；见[赞赏弹窗](./features/donation-dialog.md) |

## 托管

| 症状 | 可能原因 | 修复 |
| --- | --- | --- |
| 页面无样式 / 脚本 404 | 文件被挪动但 `index.html` 的相对路径未变，或 CSS/JS 目录未上传 | 保持目录结构完整：`index.html`、`css/`、`js/` 并列 |
| `https://<user>.github.io/password-generator/` 404 | 未启用 Pages，或来源未设为 `main` / 根目录 | 见[部署 — 首次启用](./deployment.md#首次启用新仓库) |

## 仍未解决？

到
[petrel2015/password-generator/issues](https://github.com/petrel2015/password-generator/issues)
提 Issue，附上：浏览器及版本、页面地址（或「本地文件」）、警告原文（若有）、你点过的操作。生成结果异常时请贴出设置（长度、字符类、高级选项、黑名单）——**不要**贴生成的密码本身。
