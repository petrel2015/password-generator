# 使用

PW·GEN 的日常操作说明。主 [README](../../README.zh.md) 讲「有什么」，本页讲「每个控件怎么用、边界处会发生什么」。English version: [Usage](../en/usage.md).

可以使用[在线实例](https://petrel2015.github.io/password-generator/)，也可以使用任意本地副本——见[快速开始](../../README.zh.md#快速开始)。

## 生成密码

1. 打开页面。默认设置（长度 16、四类字符全开）下会立即生成一个密码。
2. 调整长度（见下文），勾选 / 取消字符类型，填写**黑名单**，按需在**高级选项**里开启**易输入** / **易朗读** / **易复述**。
3. 每次改动都会即时重新生成——没有单独的「应用」步骤。
4. 按**重新生成**在当前设置下再抽一个新密码。
5. 按**复制**把密码复制到剪贴板，按钮会短暂显示「已复制」作为确认。

## 设置长度

- 范围 **4–64** 位。
- 滑杆与数字输入框双向同步；在输入框键入数字，滑杆随之移动。
- 输入越界值（如 `2` 或 `99`）会在失焦或点「重新生成」时收敛到 4 / 64。
- 最小长度 4 同时保证了四类字符全选时每类都至少能出现一次。

## 选择字符类型

四个独立开关：

| 类型 | 字符 | 数量 |
| --- | --- | --- |
| 大写字母 | A–Z | 26 |
| 小写字母 | a–z | 26 |
| 数字 | 0–9 | 10 |
| 符号 | ``!@#$%^&*()-_=+[]{};:'",.<>?/~\`|`` | 32 |

- 全选时候选池为 94 个字符。
- **每个勾选的类型保证至少出现一个字符**；其余位置从合并后的候选池抽取，最后整体洗牌，保底字符不会挤在开头。
- 取消勾选会缩小候选池——熵值读数会如实反映代价。设计细节见[密码生成引擎](./features/password-engine.md)。

## 读取熵值与强度

密码旁边有两个读数：

- **熵（比特）** — 按「长度 × log2(候选池大小)」计算，即当前候选池下均匀随机抽取的标准估计值。
- **强度标签 + 四段强度条**：

| 比特 | 标签 | 强度条 |
| --- | --- | --- |
| < 40 | 较弱 | 4 段中 1 段 |
| 40 – 59 | 一般 | 4 段中 2 段 |
| 60 – 79 | 强 | 4 段中 3 段 |
| ≥ 80 | 极佳 | 4 段全亮 |

默认设置（16 位、池 94）下约 105 比特。强度条衡量的是**生成器设置**，与密码是否好记、你是否会安全使用无关——真正随机的 105 比特字符串已远超任何现实暴力破解能力。

## 高级选项

上方的四个字符类型开关是基本控制。「03 — 高级选项」区块收纳三个独立模式，针对你实际**使用**密码的方式——手敲、朗读、口述——各自优化，可自由组合；每开一个，候选池随之缩小，熵值读数永远说真话。

### 易输入

剔除容易看错、敲错的字符：

- 全池剔除：`0 O o 1 l I i 2 Z z 5 S s 8 B 6 b 9 g q`
- 符号整体替换为清晰醒目的子集：`!@#$%^&*-_=+?~`

候选池从 94 缩到 55（16 位约 92 比特）。适合手工输入、纸面誊抄的场景。

### 易朗读

剔除**读出来**容易听混的字符，电话里逐字念也不会歧义：

- 剔除字母（大小写同剔）：同发 /iː/ 音的 `B C D E G P T V Z`，以及与留下的 `M`（"em"）相近的 `N`（"en"）。
- 剔除数字 `1` 和 `7`——中文「一 / 七」是经典的电话听混对。
- 符号收缩为名字短而清晰的子集：`!@#$%*+=?`。

候选池从 94 缩到 49。

### 易复述

把密码按 4 位一组分段，逐段朗读、抄写更省力：`k3WF-pmQx-…`。分隔符提供两种——连字符 `-` 或下划线 `_`——在勾选框右侧的小切换器里选择。

- 分隔符纯属排版：**不**贡献熵，熵值读数只统计真实字符。
- 选中的分隔符会从候选池中剔除，口述时不会出现「结构分隔符」与「密码内容」的歧义。
- **复制**复制的是分段后的字符串——这正是本模式的目的：粘贴到任何地方，按段念出来。

## 黑名单

在**黑名单**输入框里键入任何字符，它们都会即时从候选池中移除。

- 黑名单在高级选项过滤**之后**生效，两者可叠加。
- 被排空的字符类自动跳过（不再参与保底规则）。
- 若整个候选池耗尽，生成停止并提示「没有可用字符了——请调整黑名单。」，直到你修正输入。

典型用途：剔除目标系统不接受的字符、为 shell 引号安全去掉引号、去掉键盘敲不出的符号。

## 错误与边界行为

| 情形 | 行为 |
| --- | --- |
| 一个字符类型都没选 | 密码区显示占位符并警告「请至少选择一种字符类型。」 |
| 黑名单把候选池排空 | 停止生成并警告「没有可用字符了——请调整黑名单。」 |
| 键入长度小于 4 / 大于 64 | 变更时收敛到 4 / 64；滑杆不会越界 |
| 相同设置下反复点「重新生成」 | 每次都是独立的新密码 |
| 非安全上下文中复制 | 剪贴板 API 失败 → 旧式 `execCommand` 兜底；若也失败，按钮不会闪「已复制」——请手动选中文本复制 |
| 无 Web Crypto 的浏览器 | 核心抛出「Web Crypto API unavailable」；现代浏览器（Chrome、Edge、Firefox、Safari）均具备 |

## 切换语言

页眉的 **EN / 中文** 按钮切换整个界面，包括动态文案（熵单位、强度名称、警告）。你的选择会存入 localStorage 的 `pg-lang` 键（这也是本页唯一存储的东西——见[隐私](./privacy.md)）。首次访问时跟随浏览器语言。

## 赞赏弹窗

![赞赏弹窗与实时生成的二维码](../img/donation-dialog-en.webp)

页脚的「☕ 请作者喝杯咖啡」入口会打开一个双标签页小弹窗：

- **桌面端：** 两个标签页都在打开瞬间于浏览器本地生成二维码，用对应 App 扫码即可。
- **手机端 · 支付宝：** 点按标签页会尝试跳转官方支付宝链接；若 App 未打开，弹窗会自动回退到二维码，「显示二维码」按钮也始终可用。
- **手机端 · 微信支付：** 始终显示二维码；微信深度链接是支付载荷，浏览器无法可靠拉起。

用 × 按钮、点击遮罩或 ESC 键关闭。弹窗不会回报任何信息——无统计分析、无支付结果追踪。设计细节见[赞赏弹窗](./features/donation-dialog.md)。

## 移动端布局

![移动端布局（中文界面）](../img/mobile-zh.webp)

小屏下页面为单栏布局，所有控件无需横向滚动即可触达。语言切换、复制、赞赏弹窗与桌面端行为完全一致。
