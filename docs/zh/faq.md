# 常见问题

English version: [FAQ](../en/faq.md).

## 我的密码会离开这个页面吗？

不会。生成完全由浏览器内的 Web Crypto API 完成；页面运行时不发起任何网络请求，除了语言选择外不存储任何内容。代码级的逐条核实见[隐私说明](./privacy.md)。

## 离线能用吗？可以自托管吗？

都可以。站点就是几个静态文件，资源全为相对路径——保存仓库后直接打开 `index.html`（`file://`）、用任意静态文件服务器伺服、或部署到任何主机均可。无构建、无环境变量、无后端。

## 为什么开启高级选项后熵值下降？

每个高级过滤都整组剔除字符：**易输入**把候选池从 94 缩到 55，**易朗读**缩到 49，两者叠加缩到 35。每个位置的可能性变少意味着每字符比特数变少（log2 94 ≈ 6.55 对 log2 55 ≈ 5.78）。读数永远反映真实代价——16 位易输入密码仍有约 92 比特，远超暴力破解范围。

## 最大长度为什么是 64？

产品决策：64 个均匀随机字符已超过任何合理需求（全 ASCII 的 64 位密码约 419 比特），有界滑杆让界面保持诚实。需要更长的字符串可在 Node 中调大 `length` 运行核心——见[密码生成引擎 — 详细行为](./features/password-engine.md#详细行为)。

## 能排除特定字符吗？

能——把它们键入**黑名单**输入框。输入的每个字符都会从候选池移除；被整类排空时该类自动跳过。见[使用 — 黑名单](./usage.md#黑名单)。

## 支持哪些浏览器？

任何具备 Web Crypto API 的浏览器：当前的 Chrome、Edge、Firefox、Safari（桌面与移动端）。不支持 IE 11。复制按钮需要安全上下文（HTTPS、localhost 或 file://），否则回退旧式复制方案。

## 设置会在两次访问之间保留吗？

只有界面语言会。长度、字符类、高级选项、黑名单刻意在刷新后重置——你的密码使用习惯不在本机留痕。

## 强度条是一种保证吗？

它衡量的是**生成器**，不是你的使用方式：分数假设字符串均匀随机（本工具确实如此），对密码复用、钓鱼、键盘记录一无所知。本页产出的四段全亮字符串在暴力破解意义下不可破；其余属于操作安全。

## 手机上微信标签页为什么只显示二维码？

微信的 `wxp://` 深度链接是支付载荷，手机浏览器无法可靠拉起，因此组件对微信刻意从不尝试跳转——始终渲染二维码。支付宝的官方 `https://` 链接是普通 URL，会尝试跳转并自动回退二维码。见[赞赏弹窗](./features/donation-dialog.md)。

## 能把赞赏组件用到我自己的站点吗？

可以，它正是按此构建——自包含即插即用，只需要一个 `[data-donation]` 挂载点、`css/donation.css` 和脚本，可选地跟随已有的 `PG.i18n`。把 `DONATION_CONFIG` 里的支付链接换成你自己的即可。接入说明见[赞赏弹窗 — 方案概览](./features/donation-dialog.md#方案概览)。
